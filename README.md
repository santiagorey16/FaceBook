# FaceBook

Proyecto desarrollado en Android Studio utilizando Kotlin.

## Descripción

Aplicación móvil creada con fines académicos para practicar el desarrollo de interfaces y funcionalidades en Android.

## Tecnologías utilizadas

- Android Studio
- Kotlin
- Jetpack Compose
- Git
- GitHub

## Funcionalidades

- Desarrollo de interfaces móviles.
- Navegación entre pantallas.
- Uso de componentes de Jetpack Compose.
- Organización de elementos mediante Row, Column y Box.

## Cómo ejecutar el proyecto

1. Abrir el proyecto en Android Studio.
2. Esperar a que Gradle termine de sincronizar.
3. Seleccionar un emulador o dispositivo Android.
4. Presionar el botón Run.
